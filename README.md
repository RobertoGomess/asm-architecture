# asm-architecture

Repositório de documentação de arquitetura (pós-graduação em Arquitetura de Software).

## Estrutura

| Pasta | Conteúdo |
|-------|----------|
| `architecture/` | Modelo C4 (Structurizr DSL), diagramas e princípios arquiteturais |
| `requirements/` | Requisitos funcionais (RF) e não funcionais (RNF) |
| `adr/` | Architecture Decision Records |
| `rfc/` | Requests for Comments (propostas de mudança) |
| `event-storming/` | Comandos, eventos, políticas e linha do tempo |
| `domain/` | Bounded contexts, agregados e modelo de domínio |
| `documentation/` | Arquitetura, integrações e deployment |
| `references/` | Livros, artigos e papers |
| `templates/` | Templates de ADR, RFC e RF |

## Como contribuir

1. Use os templates em `templates/`.
2. Numere ADRs e RFCs sequencialmente (`ADR-003-...`, `RFC-002-...`).
3. Abra um Pull Request para revisão.
