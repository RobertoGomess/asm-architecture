# ADR-001: Adoção do modelo C4 para documentação arquitetural

- **Status:** Aceito
- **Data:** AAAA-MM-DD

## Contexto
Precisamos de uma forma padronizada e versionável de documentar a arquitetura.

## Decisão
Adotar o modelo C4 descrito em Structurizr DSL (`architecture/c4/workspace.dsl`).

## Consequências
- (+) Diagramas versionados junto ao código.
- (+) Linguagem comum entre times.
- (–) Curva de aprendizado da DSL.
