# ADR-002: Event Storming para descoberta do domínio

- **Status:** Aceito
- **Data:** AAAA-MM-DD

## Contexto
É necessário entender o domínio e delimitar bounded contexts.

## Decisão
Realizar sessões de Event Storming e registrar resultados em `event-storming/`.

## Consequências
- (+) Entendimento compartilhado do negócio.
- (+) Base para identificar agregados e contextos.
- (–) Exige participação de especialistas de domínio.
