# C4 Model

Modelo arquitetural descrito em [Structurizr DSL](https://docs.structurizr.com/dsl) no arquivo `workspace.dsl`.

## Como visualizar

```bash
docker run -it --rm -p 8080:8080 -v $(pwd):/usr/local/structurizr structurizr/lite
```

Acesse http://localhost:8080.
